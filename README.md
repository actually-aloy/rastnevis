# راست‌نویس (Rastnevis) 🚀

**تبدیل هوشمند فینگلیش به فارسی | تبدیل صدا به متن**

راست‌نویس یک ابزار سبک و کاربردی برای ویندوز است که با هدف ساده‌سازی تایپ فارسی طراحی شده. اگر با صفحه‌کلید استاندارد انگلیسی تایپ می‌کنید اما می‌خواهید خروجی‌تان فارسی باشد، یا دوست دارید با استفاده از صدای خود متون را تایپ کنید، این نرم‌افزار دقیقاً همان چیزی است که نیاز دارید.

## ✨ ویژگی‌ها

- **تبدیل فینگلیش به فارسی:** با یک کلیک، متن انگلیسی (مثلاً `man khosham nemiad`) را به فارسی روان (`من خوشم نمیاد`) تبدیل کنید.
- **تبدیل صدا به متن (Speech to Text):** قابلیت تبدیل هم‌زمان صدای شما به متن (با پشتیبانی از مدل‌های مختلف).
- **دیکشنری هوشمند:** اولویت تبدیل با کلمات موجود در دیکشنری است و در ادامه، قوانین دقیق تبدیل حروف چندکاراکتری و تک‌کاراکتری (مثل `sh` به `ش`) اعمال می‌شود.
- **طراحی مدرن و تاریک (Dark Mode):** رابط کاربری جذاب با قابلیت خاموش/روشن کردن انیمیشن‌ها برای کاهش مصرف منابع سیستم.
- **سیستم Tray (سینی سیستم):** برنامه می‌تواند بدون بسته شدن کامل، در پس‌زمینه اجرا شود.
- **اجرای خودکار:** امکان تنظیم برنامه برای اجرای خودکار به محض روشن شدن ویندوز.

## 🎙️ درباره بخش گفتار به متن

برنامه از شما در انتخاب مدل صوتی (ماژول) محدودیتی ایجاد نمی‌کند. شما می‌توانید از مدل‌های دقیق‌تر و کامل‌تر موجود در تنظیمات استفاده کنید (مانند مدل‌های `vosk`). 
با این حال، **اگر نمی‌خواهید زمان و حجم اینترنت خود را صرف دانلود مدل‌های حجیم کنید، برنامه با یک مدل سبک و پیش‌فرض به‌خوبی کار می‌کند.** یعنی حتی بدون هیچ تنظیم اضافی، می‌توانید بلافاصله از قابلیت تبدیل صدا به متن استفاده کنید.

## 🖥️ نیازمندی‌های سیستم

- سیستم‌عامل: ویندوز
- فضای ذخیره‌سازی کم (به جز در صورت دانلود مدل‌های صوتی بزرگ)
